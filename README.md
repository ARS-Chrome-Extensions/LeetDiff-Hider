## Overview

LeetDiff Hider is a lightweight Chrome extension that hides **Easy**, **Medium**, and **Hard** difficulty labels on LeetCode.

Difficulty labels can unintentionally influence how you approach a problem. By hiding them, you can focus entirely on understanding and solving the problem without preconceived expectations.

---

## Features

- Hide Easy, Medium & Hard difficulty labels
- Instant one-click toggle
- 100% Local (No analytics or tracking)
- Lightweight and fast
- Manifest V3
- Open Source
- Beautiful popup interface
- Settings synced using Chrome Storage

## Installation

1. Download the latest ZIP from the Releases page.
2. Extract the ZIP.
3. Open:

```
chrome://extensions
```

4. Enable **Developer Mode**.
5. Click **Load unpacked**.
6. Select the extracted **extension** folder.
7. Done
